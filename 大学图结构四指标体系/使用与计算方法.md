# MIT四指标计算

## 运行

需要Python 3，仅使用标准库，无需安装第三方包。

```powershell
python 计算四指标.py "D:\用户\Desktop\daxue\大学图结构绘制\MIT\dist\MIT_四阶段底图修改 .json"
```

默认只计算第四阶段，结果在代码旁的`第4阶段输出`。使用`--stage 3`选择第三阶段，`--out 路径`指定输出。默认传播次数20000，种子20261017，beta=0.5，kappa=2。

JSON只是拓扑输入，无法单独推导学科指标。配套数据已移至相邻目录`大学图结构全学科构建及映射关系\支持数据`，脚本默认从该位置读取；可用`--support 路径`覆盖。新增或更名楼号必须同时核查学科映射，脚本不会猜测新楼学科。

## 四张表

1. `01_接近中心性.csv`：WF修正接近中心性，C=(r/(N-1))×r/Σd，r为可达其他节点数。孤立节点为0。
2. `02_中介中心性.csv`：无向图标准化最短路中介中心性，2Σ(s<t)σst(i)/σst÷[(N-1)(N-2)]。
3. `03_学科数量加权RS.csv`：RS=Σp_i p_j d_ij；学科数量为具有正权重的ISCED-F四位领域去重数K；新指标=K×RS。保留K和原始RS用于追溯。该自定义指标进一步强化学科数量，并非标准RS或独立的创新成功指标。
4. `04_信息传播新增覆盖.csv`：相邻楼栋传播概率beta×Σp_bi p_cj exp(-kappa d_ij)。对称独立级联用无向随机活边连通分量抽样计算每个起点的预期新增覆盖，并报告蒙特卡洛标准误。新拓扑上重新模拟，不复用旧结果。

边成本统一为1，图面坐标不视为真实距离。权重重新归一化，RS从距离矩阵重算。11号楼等缺少映射的节点在学科及传播表中留空；与缺失映射节点相连的传播概率为0，这是计算约定，可能低估传播，需要补数据后复算。

旧数据中的12-old映射继续别名为12，仅沿用现有项目口径，不证明历史建筑身份与MIT.nano相同。其他阶段沿用同一学科映射，属于情景模拟，不是历史学科重建。



## 交互选择输入

运行 python 计算四指标.py，不附加路径时弹出JSON文件选择窗口；无图形环境或取消选择后可粘贴路径，直接回车退出。也可以继续用命令行传入JSON路径。
