# 华工四指标计算

正式入口：`一键计算_按原公式.py`。先运行 `整理华工学科映射.py` 生成华工支持数据，然后运行入口；均仅依赖 Python 标准库。

```powershell
python 整理华工学科映射.py
python 一键计算_按原公式.py
```

正式结果位于 `正式输出`：总表、结果摘要、四个单指标CSV、AHP综合排名、权重、标准化参照、中心性敏感性排名、边传播概率和运行记录。CSV为带BOM的UTF-8，Excel可以打开。

`原公式代码`里的三个文件是指定原计算代码的完整副本，运行记录核验 SHA256 一致。未改公式、标准化和常量指标处理。原代码的stage=4只是输入适配槽，不表示华工历史第四阶段。

用户明确确认了全部提交拓扑，15节点8条边全部纳入；不按遗留confirmed字段过滤。原始JSON保存在 `../学科原始数据/用户确认拓扑_原始.json`，逐字节保留。这里的节点ID不是实际楼号，不擅自改动。

新增华工映射在 `../../大学图结构全学科构建及映射关系/华南理工大学/支持数据`，原MIT映射保留。学科原始记录、官方来源事实摘要、楼栋归属及建模假设审计在 `../学科原始数据`。

所有15节点学科为本次有来源的研究情景，含楼栋/机构外推与等份假设，证据强度见审计；拓扑确认不代表这些学科假设都得到实测确认。使用时先看 `正式输出/结果摘要.md` 与总表末尾的映射局限列。
