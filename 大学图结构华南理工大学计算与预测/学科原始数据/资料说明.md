# 华工学科资料说明

本目录记录本次15节点拓扑涉及的学科资料，不声称覆盖学校全部楼栋或全部学科。

- 用户确认拓扑_原始.json：保留原文件字节、坐标、备注与confirmed字段。用户2026-10-19明确确认全部拓扑边，运行时均纳入，未擅自修改原始输入。
- 官方资料来源索引.csv / 官方资料来源与事实摘要.json：17条官方来源、核查日期及研究者事实摘要，含历史资料；不是网站原文全文镜像，也不是资料发布日期与核查日相同。
- 楼栋学科原始与整理对照.csv：每栋原字段、整理学科、领域代码份额、证据等级及逐节点局限。
- 楼栋学科展开表.csv：每个中文学科标签到每个统一领域代码的展开记录。
- 华工楼栋学科整理记录.json：可追溯整理记录与计算映射。

必须区分三层信息：①用户确认的拓扑；②官网支持的楼址、机构和研究领域；③由学院或团队领域到楼栋的模型外推及均等份额。第①层确认并不使第③层成为实测事实。所有15节点的得分均以整理映射情景为条件。

证据等级A：官方楼址与学院领域均有支持，仍缺实测领域份额。
证据等级B：部分归属有官方支持，领域到楼栋有外推或历史资料使用。
证据等级C：主要依赖用户节点标签及有限背景材料的推定情景，需补充实际使用名单验证。

材料科学与工程、生物工程等同名标签尽量沿用MIT既有领域映射。物理电子学采用0714；物理与光学采用0533，不能将光学本身认定为0714。统一距离矩阵沿用原项目；中文学科与ISCED领域不是一一对应关系。研究标签等份，标签内代码等份，重复领域合并后归一化，不代表人员、面积或论文份额。

正式计算映射另存于“大学图结构全学科构建及映射关系/华南理工大学/支持数据”。原MIT资料未覆盖。
