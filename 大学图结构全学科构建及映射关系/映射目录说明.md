# 两所学校的统一领域映射

- `支持数据/学科映射.json`：原有 MIT 数据，原路径和内容保留。
- `支持数据/学科距离矩阵.csv`：原有149领域统一学科距离模型。
- `华南理工大学/支持数据/学科映射.json`：新增五山拓扑15节点的学科情景映射，字段采用原计算脚本需要的 node / fields / code / share。
- `华南理工大学/支持数据/华工楼栋学科映射审计.csv`：逐节点来源、证据等级及限制。
- `华南理工大学/支持数据/华工学科标签到ISCED映射.csv`：整理的学科标签和项目统一领域代码。

华工学科原始输入及来源事实索引保存在相邻项目 `大学图结构华南理工大学计算与预测/学科原始数据`。华工领域份额采用等标签、标签内等代码并合并归一化；不是实测份额。MIT与华工使用同一距离矩阵，学校的楼栋映射分别保存，不混用楼号或节点编号。
